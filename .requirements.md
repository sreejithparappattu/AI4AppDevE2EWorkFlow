## Budget pro
Budget pro is a web based budgeting application designed to allow users to manage their finances effectively. It provides tools for tracking income, expenses, and savings goals, helping users to make informed financial decisions.

following are some of the key features of Budget pro:
ability to register and create a personal account for secure access to financial data.
- Dashboard for an overview of financial status, including income, expenses, and savings.
-ablityt to enter their income and expenses, categorize them, and view detailed reports
